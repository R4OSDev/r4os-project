R4OS Shell und Befehlsausfuehrung - Agent-Referenz
==================================================

Zweck: Verlaessliche Host-Aufrufe unter Windows und eine kompakte Referenz
fuer die produktive R4OS-Terminal-Shell.


Host-Shell: Grundregeln
-----------------------

- Der normale Workspace-Einstieg laeuft ueber PowerShell und ruft teilweise
  Batchdateien auf. Bash ist nur bei einem ausdruecklichen `Build.sh`-Aufruf
  beteiligt und darf nicht still vorausgesetzt werden.
- Fuer Dateipfade in PowerShell `-LiteralPath` verwenden und den Arbeitsordner
  bewusst setzen. Keine Pfade durch unkontrollierte Stringverkettung bauen.
- Komplexe Texte mit Backslashes, Backticks, regulaeren Ausdruecken,
  Zeilenumbruechen oder verschachtelten Anfuehrungszeichen gehoeren in eine
  Datei beziehungsweise in einen gezielten Patch, nicht in eine mehrfach
  interpretierte Kommandozeile.
- Lokale Dateiaenderungen mit dem Patch-Werkzeug ausfuehren. Mechanische
  Formatierung darf danach mit einem dafuer bestimmten Werkzeug erfolgen.
- Erfolg wird am Exitcode gemessen. PowerShell 5.1 kann stderr nativer
  Programme als `NativeCommandError` darstellen, obwohl deren Exitcode 0 ist.


Batch und Commit-Beschreibungen
-------------------------------

Commit-Beschreibungen zuerst in eine PowerShell-Variable legen und ohne
eingebettete doppelte Anfuehrungszeichen an `Tools/Github.bat` uebergeben.
Wo Zitate im Text noetig sind, einfache Anfuehrungszeichen verwenden.

Ein Batchstarter muss bis zu seinem Exitcode laufen. Ausgabe wie `ERFOLG` oder
`FAILED` ersetzt nie die Auswertung von `$LASTEXITCODE` beziehungsweise
`%ERRORLEVEL%`.


PowerShell-Skripte und Gates
----------------------------

Eigenstaendige PowerShell-Pruefungen mit `powershell -File <Script>` oder dem
gleichwertigen vollstaendigen `-File`-Aufruf starten. Ein Aufruf ueber den
PowerShell-Aufrufoperator kann in `$LASTEXITCODE` nur den letzten nativen
Unterprozess hinterlassen und damit das Ergebnis des eigentlichen Skripts
verschleiern.

Vor einem schreibenden Mehrrepository-Aufruf immer bestimmen, welchem
Repository die betroffenen Dateien gehoeren. GitHub-Push und -Pull erfolgen
ausschliesslich nach `Agents/Github.txt`.


SSH zum QEMU-Gast
-----------------

Ein vorhandenes Full-Image auf dem jeweiligen Host headless starten:

    Tools\Build.bat -ssh
    ./Tools/Build.sh -ssh

Der Start bleibt im Vordergrund, verwendet das persistente Full-Datenimage und
schreibt die serielle Ausgabe nach
`Artifacts/Distribution/Logs/qemu-ssh-debug.log`. Sobald der Gast gebootet
hat, verbindet ein zweites Host-Terminal die lokale Weiterleitung
`127.0.0.1:10022 -> 10.0.2.15:22`:

    ssh -p 10022 -c chacha20-poly1305@openssh.com r4os@127.0.0.1

Passwort: `rosebud`.

Nach der Anmeldung zuerst `VER` ausfuehren und damit Ziel und Version
bestaetigen. `EXIT` beendet nur die SSH-Sitzung; `POWEROFF` beendet den Gast
und damit den wartenden QEMU-Aufruf. Auch der sichtbare normale QEMU-Modus
besitzt diese Weiterleitung. Sie bleibt auf `127.0.0.1`; eine externe Firewall-
oder Routerfreigabe ist weder noetig noch gewuenscht. SSH- oder andere R4OS-
Serviceports niemals in ein oeffentliches oder nicht vertrauenswuerdiges Netz
weiterleiten.


R4OS-Terminal: Orientierung und Systemstatus
---------------------------------------------

    HELP                    Interne Terminalbefehle auflisten
    HELP /S                 Terminalprogramme im aktuellen PATH auflisten
    <PROGRAMM> /?           Programmspezifische Hilfe anzeigen
    VER                     Release sowie aktive/installierte Kernelversion
    SYSINFO                 System-, Hardware-, Speicher- und Netzuebersicht
    BOOTINFO /SUMMARY       Kompakte Bootinformationen
    BOOTINFO /FB            Framebuffer-Informationen
    BOOTINFO /MAP           Speicherkarte ausgeben
    DATE                    Datum anzeigen
    TIME                    Uhrzeit anzeigen
    VOL                     Informationen zum aktuellen Laufwerk anzeigen


R4OS-Terminal: Dateien und Verzeichnisse
-----------------------------------------

    DIR [Pfad]              Verzeichnisinhalt anzeigen
    CD [Pfad]               Arbeitsverzeichnis anzeigen oder wechseln
    C: / D:                 Zu einem eingehangenen Laufwerk wechseln
    TYPE <Datei>            Textdatei ausgeben
    MORE <Datei>            Textdatei seitenweise ausgeben
    SORT <Datei>            Textdatei sortiert ausgeben
    COPY <Quelle> <Ziel>    Eine Datei kopieren
    REN <Alt> <Neu>         Datei umbenennen
    DEL <Datei>             Eine Datei loeschen
    MD <Verzeichnis>        Verzeichnis erstellen
    RD <Verzeichnis>        Leeres Verzeichnis entfernen

`>` und `>>` funktionieren fuer eingebaute Terminalbefehle. Pipes, Eingabe-
Redirection und Redirection externer R4X-Programme sind noch nicht verfuegbar.


R4OS-Terminal: Sitzung
----------------------

    PATH                    Suchpfad der Sitzung anzeigen
    PATH /P                 Persistenten System-PATH anzeigen
    PATH /P <Wert>          Persistenten System-PATH setzen
    SET                     Unterstuetzte Umgebungsvariablen anzeigen
    PROMPT <Wert>           Prompt der Sitzung setzen
    ECHO <Text>             Text ausgeben
    CLS                     Terminal leeren
    PAUSE                   Auf einen Tastendruck warten
    SLEEP <Millisekunden>   Warten, hoechstens 600000 Millisekunden
    EXIT                    Terminal- oder SSH-Sitzung sauber beenden


R4OS-Terminal: Dienste
----------------------

    SERVMAN LIST                    Alle Dienste anzeigen
    SERVMAN STATUS <Name>           Dienst- und Endpoint-Status anzeigen
    SERVMAN DIAG                    Zusammenfassende Dienstdiagnose
    SERVMAN START <Name>            Dienst starten
    SERVMAN STOP <Name>             Dienst stoppen
    SERVMAN RESTART <Name>          Dienst neu starten
    SERVMAN ENABLE <Name>           Dienst aktivieren
    SERVMAN DISABLE <Name>          Dienst deaktivieren

Fuer die Fernwartung besonders nuetzlich:

    SERVMAN STATUS SSHD
    SERVMAN STATUS TCPSVC
    SERVMAN DIAG


R4OS-Terminal: Netzwerk
-----------------------

    IPCONFIG                        Aktuelle Netzwerkkonfiguration
    IPCONFIG /ALL                   Ausfuehrliche Netzwerkdiagnose
    IPCONFIG /RENEW                 DHCP-Lease erneuern
    IPCONFIG /RELEASE               DHCP-Lease freigeben
    DHCP STATUS                     DHCP-Status anzeigen
    DHCP ACQUIRE                    Neue DHCP-Lease beziehen
    DHCP RENEW                      DHCP-Lease erneuern
    DHCP RELEASE                    DHCP-Lease freigeben
    PING <Adresse|Hostname>         Erreichbarkeit pruefen
    PING -t <Adresse|Hostname>      Fortlaufend pingen; Abbruch mit Strg+C
    DNSLOOKUP <Hostname> [Server]   DNS-Aufloesung pruefen
    HTTPGET <http-URL> [Datei]      HTTP-Ressource abrufen
    NETCAT <Host> <Port> [Text]     TCP-Verbindung und Payload pruefen
    NETCAT /INTERACTIVE <Host> <Port>
                                    Interaktive TCP-Sitzung
    NETCAT /LISTEN [Port] [Antwort] TCP-Listener fuer einen Test starten
    TCPECHO [Host] [Port] [Text]    TCP-Echo-Test ausfuehren


R4OS-Terminal: Registry und Updates
-----------------------------------

    REG ROOTS                       Registry-Wurzeln anzeigen
    REG ENUM SYSTEM\<Pfad>           Werte eines Registry-Schluessels auflisten
    REG QUERY SYSTEM\<Pfad> [Wert]   Registry-Wert lesen
    SYSUPD STATUS                   Update- und Journalstatus anzeigen
    SYSUPD VERIFY <Paket.R4U>       Paket vollstaendig pruefen

Schreibende Registry-Befehle sowie `SYSUPD APPLY`, `SYSUPD STAGE`,
`SYSUPD COMMIT` und `SYSUPD RESUME-BATCH` nur auf ausdruecklichen Auftrag
ausfuehren.


R4OS-Terminal: Systemsteuerung
------------------------------

    DESKTOP                 Im Terminal-Modus zum Desktop zurueckkehren
    REBOOT                  System neu starten
    POWEROFF / SHUTDOWN     System ausschalten
    HALT                    System anhalten

`DEL`, `RD`, schreibende `REG`-Befehle, Dienststeuerung und
Systemsteuerungsbefehle veraendern den Gastzustand. Vor ihrer Verwendung Ziel
und Auftrag pruefen.


Empfohlene erste Remote-Diagnose
--------------------------------

    VER
    SYSINFO
    IPCONFIG /ALL
    SERVMAN DIAG
    SERVMAN STATUS SSHD
